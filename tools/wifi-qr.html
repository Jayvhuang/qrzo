Frequently asked questions

How does a WiFi QR code work?

It encodes your SSID and password in the standard WIFI: format, so phones join the network with one tap.

Is it safe to share my password this way?

The code contains your password in plain form, so only share it with people you trust, or use a guest network.

Which encryption types are supported?

WPA/WPA2/WPA3, WEP, and open (no-password) networks.
